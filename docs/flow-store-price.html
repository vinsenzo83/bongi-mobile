매장 · 휴대폰 시세 플로우

어드민 08~09번 메뉴 · 8개 직영점 · 18개 5G 모델 + 저가/오픈박스 · 매장 방문 유도
핵심 — 휴대폰은 매장에서만 개통
플랫폼에서 안 하는 것
휴대폰 온라인 개통 ❌
→ 휴대폰은 매장에서만 개통 가능
→ 플랫폼은 시세 안내 + 매장 방문 유도만
플랫폼이 하는 것
시세 확인 → 매장 선택 → 방문/전화
→ AI 채팅에서 시세 카드 표시
→ 고객이 매장 방문하면 DB 확보
목적: 시세를 보여주고 매장 방문을 유도하여 DB를 확보한다. 연 6만명 매장 개통 고객 → CRM 자동 유입.

예외 케이스 — 매장 · 휴대폰 시세
상황처리 방법
시세 미업데이트어드민에 경고 배너 표시. 마지막 업데이트 일시 노출.

공시지원금 변경smartchoice.or.kr 매일 09시 자동 크롤링. 변경 감지 시 어드민 알림.
모델 단종/신규어드민에서 모델 추가/비활성. AI 채팅 자동 반영.
매장 휴업운영중/휴업 토글. 휴업 시 고객에게 안 보임.
매장 방문 후 앱 미가입CRM에 등록됨 → 알림톡으로 앱 가입 유도 → 전화번호 매칭.
