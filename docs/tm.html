💬 4단계 상담 스크립트

1. 인사 & 본인확인
안녕하세요, 리턴AI 상담사 ___입니다. 인터넷·TV 상담 도와드리겠습니다. 본인이신가요?
2. 현재 상품 확인
현재 어느 통신사 사용 중이신가요? 약정 만료일은 언제인가요? 가족 결합 여부도 확인.
3. 견적 안내
오른쪽 견적표를 보고 안내드립니다. 사은품 · 설치비 함께 설명. 결합 할인 강조.
4. 클로징
신청 의사 확인 → 설치 일정 협의 → 필요 서류 안내 (신분증·계좌·주소).
