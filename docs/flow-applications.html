신청 현황 플로우

어드민 10번 메뉴 (show(6)) · 모든 유입 경로 통합 뷰 · CRM 양방향 실시간 동기화
핵심 -- 모든 유입 경로 통합
신청 현황 = 플랫폼 발생 + 외부 발생 모든 신청을 하나의 화면에서 관리.
플랫폼(셀프신청/티켓/AI채팅) -> 어드민 -> CRM 동기화 / 외부(CRM등록) -> CRM -> 어드민 역동기화.
전화번호 = 핵심 키 (중복 방지 + 자동 매칭 + 회원/비회원 구분)
플랫폼 발생 (어드민->CRM)
셀프신청 / 티켓 / AI채팅
고객이 앱/웹에서 직접 신청
-> bongi_applications 저장 (중고폰 매입 제외 — 별도 bongi_used_phone_buyback)
-> CRM으로 자동 푸시
외부 발생 (CRM->어드민)
CRM 등록 (전화 인입 등)
상담사가 CRM에 직접 등록
-> 어드민으로 실시간 역동기화
-> 티켓번호 없음 (상담 시 확정)
양방향 동기화
상태 변경: CRM <-> 어드민 실시간
신청완료 -> 상담중 -> 계약완료/취소
어느 쪽에서든 변경 -> 양쪽 반영
동기화 방향 컬럼으로 추적

STEP 6 -- 계약완료 후 흐름
계약완료 시 자동 트리거되는 3가지
1. 사은품 자동 생성
계약완료 -> 사은품 관리(13번)에
"지급 대기" 건 자동 생성

앱회원: 본인인증 + 계좌 등록 완료 시 즉시 지급
비회원: "비회원 대기" 상태 -> 앱 가입 유도
사은품 = 전액 현금 지급
2. 포인트 자동 적립
앱회원만 적립 가능 (비회원 불가)

친구초대 계약 (추천인)인터넷15K / TV20K / 렌탈10K
친구초대 계약 (친구)인터넷10K / TV15K / 렌탈5K
후기 작성15,000P
3. 비회원 알림톡 자동 발송
3단계 자동 발송:

1차: 신청 완료 즉시
"앱 가입 + 계좌 등록 시 사은품 즉시 지급"

2차: 계약 완료 시
"사은품 OO만원 준비됨 -> 앱 가입 -> PASS 인증 -> 계좌 등록 -> 즉시 입금"

3차: D+7 (미가입 시)
"사은품이 아직 대기 중이에요"
계약완료 전체 후속 처리 플로우
