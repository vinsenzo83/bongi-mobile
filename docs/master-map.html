회원 유형별 데이터 연결
고객 유형 4가지
유형유입 경로데이터 보유
앱회원카카오/구글 로그인이름·전화·소셜·PASS(선택)·마이페이지
비회원(셀프)셀프신청이름·전화·주소·계좌
비회원(CRM)전화/매장이름·전화 (CRM에서 수집)
비회원(중고폰)매입 접수이름·전화·생년월일·성별·통신사 (PASS 완료)
전화번호 = 핵심 키
· 어떤 경로로 유입돼도 전화번호 기준 한 고객으로 통합
· 비회원 → 앱 가입 시 전화번호로 자동 매칭
· 셀프신청/CRM/중고폰 데이터 모두 연결
· 중고폰 고객은 PASS 인증 완료 상태 → 앱 가입 시 재인증 불필요
이름 자동 수정 우선순위:
PASS 실명 > 카카오 실명 > 구글 입력 > 셀프신청 입력 > CRM 입력

PASS 인증으로 확보: 실명 · 생년월일 · 성별 · 통신사 · CI(고유값)
