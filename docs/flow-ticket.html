어드민 09번 메뉴 · 인터넷 1,002개 + 렌탈 51개 = 총 1,053개 · 조합 자동 생성
핵심 — 티켓번호란?
티켓번호 = 상품 조합의 고유 식별 코드. 발급이 아님. 상품에 부여된 고정 코드.
고객이 AI 채팅에서 상품 탐색 → 티켓번호 확인 → 콜센터 전화 시 "SK0188이요" → 상담사 즉시 파악.
인터넷+TV (조합 상품)
속도 × TV × 셋톱 × WiFi = 티켓 1개
예: SKT 500M + Btv 스탠다드 + AI NUGU + WiFi6
= SK0188 (월 53,900원)
렌탈 (1:1 매핑)
상품 1개 = 티켓 1개 (조합 없음)
예: 코웨이 아이콘3 냉온정 정수기
= R001 (월 14,450원)

기존 R001~R051은 그대로 유지
핵심 원칙 4가지
① 티켓번호는 한번 발급되면 영원히 해당 조합을 가리킨다
② 삭제는 없다 — 비활성만 있다
③ 비활성 티켓은 신규 신청 불가, 기존 주문은 참조 가능
④ 번호는 절대 재사용하지 않는다 (SK0451 다음은 SK0452)
