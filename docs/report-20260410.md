- 어드민 25개 메뉴 전체 Supabase DB 연동 완료

- 보안: 출금 PostgreSQL RPC 원자적 처리 (race condition 방지)

### 04/09 (수) — 피그마 연동 + UI 리디자인 + 문서 정비

- **피그마 API 연동**: Figma Personal Access Token으로 13개 디자인 자동 추출
- **전체 UI 리디자인** (7개 컴포넌트):
    - ProductCard: 다크→라이트 테마, 피그마 카드 구조
    - ConsultSheet: 다이렉트 상담 + 셀프 가입 2경로
    - InternetSelectCard: 5단계 바텀시트 (통신사→속도→TV→셋톱→WiFi) + 실시간 가격
    - RentalSelectCard: 2단계 바텀시트 (12개 카테고리→브랜드)
    - PhoneSelectCard: 4단계 바텀시트 (통신사→유형→제조사→기종)
    - UsedPhoneSelectCard: 중고폰 시세 + 등급별 보상시세
    - designTokens.js: 공통 디자인 시스템 (컬러/폰트/스타일)
- 어드민 회원 상세 팝업 8탭 API 실시간 로드
- 출금 승인 4중 조건 검증 (5만P + PASS인증 + 계좌등록 + 계약1회)
- 어드민 개발 관리 패널 (스펙/이슈 DB 공유)
- 플로우 문서 12개 최신 동기화 + 스텝별 메모 기능

### 04/10 (목) — 마이페이지 완성 + 보고서

- 마이페이지 API 연동 **8/8 완료**:
    - ReferralTab: 추천코드 조회 + 친구 통계
    - GuardTab: 알람 API + D-day 계산 + ON/OFF 토글
    - ProfileTab: 회원 프로필 조회
    - AccountTab: 계좌 조회/등록
- master-map.html 개발자 참고 URL + API 엔드포인트 테이블 추가
