상황처리 방법
렌트리 URL 변경/삭제이미지는 Supabase에 복사되어 있으므로 영향 없음. 상품 데이터도 DB에 저장.
렌트리에 없는 상품수동 등록 가능 (URL 파싱 없이 직접 입력)
상품 단종비활성 처리 → 티켓(R00X) 자동 비활성. 삭제 불가.
월요금 변경어드민에서 수정. 기존 계약은 계약 시점 요금 유지.
제휴카드 변경카드사/실적/할인액 수정. 티켓 영향 없음.
사은품 종류 변경현금→반값 or 반값→현금 변경 가능. 신규 신청부터 적용.
이미지 깨짐Supabase Storage에 복사되어 있어 렌트리 URL 변경 시에도 안 깨짐.
