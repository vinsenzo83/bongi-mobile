7 · 부가서비스 구성 (3분류)
분류예시정체·구현봉이 반영
① 공급사 속성핫스팟·음성·데이터쉐어 · 검열 우회(중국서 구글·ChatGPT·카톡, CMLink "Enjoy Popular APP")공급사 상품에 딸림 → 우회 지원 상품 선택·노출(봉이가 망 못 건드림)중국·검열국 우회 상품 큐레이션 + "구글·ChatGPT 그대로" 셀링
② 저속무제한 마케팅"구글맵·카톡 무료"(데이터 다 써도 지도 안 끊김)zero-rating 아님. "고속 X GB + 소진 후 저속 무제한" 구조 → 저속으로도 지도·메신저 작동 → 여행자 불안(길 잃음) 해소로 표현같은 구조 상품 + 안내 문구 자유("다 써도 지도·카톡 계속")
③ 자체 부가안심케어(usimsaCare 30만원 보상)·번들·포인트·한국어 CS공급사 무관. 자체 약관 + 보상예산/보험제휴 + 결제옵션으로 직접 운영페이백·포인트·무인 고객센터 인프라 재사용(봉이 우위)
핵심: 부가의 대부분은 "상품 선택 + 마케팅 안내 + 자체 정책"으로 봉이가 만든다(공급사는 망 기능·우회 상품만 제공). usimsaCare·"구글맵 무료"·ChatGPT 우회 모두 봉이 재현 가능. 특히 ③ 자체 부가는 봉이가 기존 통신 인프라(페이백·포인트·CS)가 있어 신규 유심사보다 유리.
💡 "구글맵 무료"의 진실(유심사 실측): 정량 옵션도 실제론 "매일 500MB~ 이후 저속 무제한" → 저속이라도 지도는 됨 → "무료"로 표현. 별도 무과금 아님 = 봉이도 저속무제한 상품이면 동일 표현 가능.
