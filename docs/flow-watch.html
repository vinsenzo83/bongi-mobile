5필수 조건 (어드민 탭)
⚠️ 메인 회선 동시 개통
워치 단독 가입 ❌. 메인 휴대폰과 같은 명의·같은 시점 동시 개통 필수. 메인 회선이 이미 개통된 상태에서 워치만 추가는 일부 통신사만 허용 (KT만 가능, SKT·LGU+는 동시 개통 한정).
⚠️ 명의 일치
메인 회선과 동일 명의 필수. 가족 명의 워치는 부모·자녀 가족결합 시에만 예외 허용 (자녀 워치 분리).
⚠️ 24개월 약정 유지
매장지원금 = 위약금 처리. 24개월 내 해지 시 매장지원금 환수 + 통신사 위약금. 메인 회선 해지 시 워치 회선도 자동 해지.
🟡 부가서비스 (선택)
통신사별 부가서비스 가입 시 추가 할인 가능 (SKT: 워치 분실보험 · KT: 안심 서비스 · LGU+: 자녀 안심).
