## 0. 요약

빌리고 정수기 엑셀 import가 완료되면서 `rental_*`에 **1,253 모델 / 8,409 옵션 / 28 카테고리**가 적재됐다.
기존 2-pane UI는 모델 100여 개 시절 설계라 이 규모를 못 버틴다. 옵션이 한 모델당 최대 56개,
variant 차원이 92%, 카테고리가 28종으로 늘면서 **탐색·편집·검수가 모두 한계**다.
본 PRD는 3-pane 레이아웃 + variant 그룹핑 + 빌리고/봉이 2존 분리로 전면 개편한다.

## 2. 현재 UI 분석 (`#rental-panel`)

### 2.1 구조
```
[카테고리 탭: 가전렌탈]
├ KPI 4개   (총 모델 / 총 옵션 / 우수상품 / 평균 리베이트)
├ 필터 바    카테고리▾  브랜드▾  프로모션▾  Tier▾  검색

│  ├ 좌(1.2fr) 모델 마스터 테이블 — 6컬럼: 브랜드·모델/상품명/태그·약정·옵션·시장·활성
```

## 3. 목표

1. 56옵션 모델도 **한 화면에서 파악** — variant 그룹핑 + 약정 피벗
2. 28 카테고리를 **그룹 네비 + 적응 컬럼**으로 — 카테고리별 의미 있는 컬럼만
3. **빌리고존(읽기) / 봉이존(편집)** 시각 2분할 — 운영자 인지부하 ↓
4. **import 센터** — 배치 이력 · 단종 추적 · 월별 diff
5. 인센티브 구조(P·마진·Tier·정산 RPC)는 **기존 100% 유지** — UI만 개편

비목표(out-of-scope): 인센티브 계산식 변경 · 계산기(견적) 화면 · 가전 파일(2차) 파서.

### 4.2 ① 카테고리 네비

- 28종을 **6 그룹**으로 묶음:
  | 그룹 | 카테고리 |
  |---|---|
  | 정수기 계열 | 정수기 · 얼음정수기 · 냉온정수기 · 연수기 |
  | 공기·환경 | 공기청정기 · 제습기 · 방향기 · 해충방제 |
  | 생활가전 | 세탁기 · 건조기 · 식기세척기 · 청소기 · 로봇청소기 · 전기레인지 · 오븐 · 커피머신 · 음식물처리기 · 식물재배기 |
  | 침구·헬스 | 매트리스 · 침대프레임 · 안마의자 · 힐링케어 · 미용/의료기기 |
  | 디지털 | TV · PC·노트북 · 모니터 · 게임기 · 빔프로젝터 · 스피커 |
  | 기타 | 비데 · 샤워기 · 냉장고 · 김치냉장고 · 에어컨 · 의류관리기 · 의류청정기 · 펫용품 · 핸드드라이어 |
- 각 항목: `이름  [모델수 배지]  ●활성/○비활성`
- 모델 0개 카테고리는 흐리게(클릭 가능, "데이터 없음" 표시)
- 그룹 메타는 `rental_categories.metadata.group` 신규 키로 (시드 SQL 1줄)
- 활성 토글: 항목 우측 점 클릭 → `is_active` PATCH (admin 전용)

### 4.3 ② 모델 마스터 — 적응 컬럼 + 페이지네이션

- **공통 컬럼**: 브랜드 · 모델/상품명/태그 · 약정칩 · 옵션수 · 시장성 · 활성
- **적응 컬럼**: `rental_categories.metadata.extra_fields` schema로 카테고리별 추가 (이미 #37로 동적 폼 인프라 존재 — 동일 schema 재사용)
- **검색·필터**: 검색창(모델·상품·메모) + 회사 칩 멀티선택 + 프로모션·Tier 드롭다운 유지
- **페이지네이션**: 50행/페이지 (정수기 367개 → 8페이지). 클라이언트 측 slice.
- 행 클릭 → ③ 워크스페이스 로드

### 4.4 ③ 옵션 워크스페이스 — 핵심 개편

평면 테이블 폐기. 2계층 뷰:

**(a) variant 그룹 아코디언**
- `variant_label`별 접이식 섹션. 청호 규정코드 12종 → 12 그룹, 각 헤더에 옵션수·약정 범위
- variant 없는 모델(8%)은 단일 그룹 자동 펼침

**(b) 그룹 내부 — 약정 피벗 테이블**
- 행 = `care_service` × `ownership_months` (예: 방문·셀프 / 1·5년 소유)
- 열 = 약정 개월 (36 / 48 / 60M ...)
- 셀 = 월 렌탈료 · 리베이트 · 마진 (3줄 미니 카드)
- 카테고리 적응: 점검주기 컬럼은 정수기·비데 그룹만, 일시불(months=0) 모델은 "일시불" 단일 열

**(c) 빌리고 / 봉이 2존 색상**
| 존 | 컬럼 | 출처 | 편집 |
|---|---|---|---|
| 🔒 **빌리고존** (회색 배경) | 월렌탈료 · 정상가 · 리베이트·타사보상·반값리베이트 · 결합지급률 · 수수료 방식 | 빌리고 엑셀 import (월간 갱신) | **읽기전용** |
| ✏️ **봉이존** (노랑 배경) | point_weight(P) · margin · tier · payback · is_active · is_premium · 평가메모 | 운영자 입력 | **편집** |
- import은 봉이존을 **절대 덮어쓰지 않음** (PRD `billigo-rental-system` §6 보존 원칙 — UI에 명시 표기)
- 봉이존 컬럼은 모델 단위 일괄 입력 버튼 유지(`rp-bulk-payback-btn` 패턴 확장)

### 4.5 ④ import 센터

- 현재 import 모달 → **import 센터 패널**로 승격 (rental-panel 상단 탭 또는 별도 섹션)
- **배치 이력 테이블**: `rental_import_batches` — year_month · file_type · 신규/변경/단종 · status · error_message · 일시
- 배치 행 클릭 → **diff 뷰**: 신규 N모델 · 변경 N모델 · 단종 N모델 목록 (`billigo_status` · `source_batch_id` 기반)
- **단종 필터**: `billigo_status='단종'` 모델 별도 뱃지·필터 (계산기 노출 차단 확인용)
- 미리보기→확정 흐름은 현행 유지 (async commit)

### 4.6 KPI 바 재구성
총 모델 · 총 옵션 · ⭐우수상품 · 단종(신규) · 최근 import(year_month)
