## 2. 카테고리별 주요 변경

### 2-1. 🔒 보안 (CRITICAL 5건)

| 위치 | 위협 | fix |
|---|---|---|
| `tm-counselor.html` | DOM XSS (`?phone=` innerHTML 무방비) | regex sanitize (숫자·하이픈·괄호만, 20자) + textContent 분리 |
| `rental_partner_cards` | RLS OFF + 정책 0개 | RLS 재활성화 + 2 정책 (read auth · write service) |
| `/rental/partner-cards` GET | `optionalAuth` | `authenticateJWT` 적용 |
| `/rental/partner-cards` POST/PATCH/DELETE | role check 없음 (agent도 카드 추가/수정/삭제 가능) | `requireRole` 헬퍼 + admin/manager (DELETE는 admin only) |
| `/customers/unified` | contract role 콜DB 전량 노출 | 403 차단 + manager 본인 센터 IN 필터 |

### 2-2. 🚀 성능 (8건)

| 항목 | 변경 |
|---|---|
| RLS initplan | `auth.role()` → `(select auth.role())` wrapping 6개 정책 |

| FK 인덱스 누락 | 34개 신설 (양쪽) — unindexed FK 0건 |
| `incentive_customer_notes.author_id` 인덱스 | 신설 (메모 작성자별 가속) |

| uploadLimiter | 분당 15회 · 75MB cap (Storage 폭증 방지) |

### 2-3. 🛡️ 데이터 무결성

**CRITICAL 발견**: `bongi_gifts.source_sale_id`(bigint) vs `incentive_sales.id`(uuid) **type 충돌**
- 4일간 영업 완료 → 마이페이지 페이백 자동 sync 안 됨 (트리거 silent fail)
- **fix**:
  - `source_sale_id`: bigint → **text** (양쪽 sale id 호환)
  - 트리거 함수 `NEW.id::text` 명시 캐스팅
  - 데브 status constraint 영문 → **한글** 6종 라이브와 통일
  - 누락 백필: 라이브 8건 · 데브 9건
- **영향**: 완료된 8건 영업이 이제 고객 마이페이지에 정상 표시
