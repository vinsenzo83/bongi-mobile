상황예시처리 방법
전화번호 중복 비회원 A가 셀프신청 → 같은 번호로 CRM에서도 등록됨 전화번호 기준 한 고객으로 통합. 나중에 들어온 데이터가 빈 필드만 채움 (기존 데이터 유지)
이미 앱회원인데 비회원으로 신청 로그아웃 상태에서 셀프신청 → 전화번호가 기존 앱회원과 동일 전화번호 매칭 → 기존 앱회원에 신청이력 연결. 별도 비회원 생성 안 함
카카오/구글 동시 가입 카카오로 가입 후 나중에 구글로도 로그인 시도 전화번호 동일하면 기존 계정에 연결. 다르면 별도 계정 (전화번호가 키)
PASS 인증 이름 ≠ 기존 이름 셀프신청 시 "홍길동" → PASS 인증 시 "홍길순" PASS 실명으로 자동 덮어쓰기 (우선순위: PASS > 카카오 > 입력)
중고폰 고객이 앱 가입 PASS 인증 완료 상태에서 카카오로 앱 가입 전화번호 매칭 → PASS 데이터 자동 연결 → 재인증 불필요
CRM 이름 오타 TM센터에서 "홍길동"을 "홍길둥"으로 등록 카카오 실명 or PASS 인증 시 자동 수정
비회원이 계좌만 없음 셀프신청에서 계좌 미입력 → 계약완료 사은품 보류 → 앱 가입 유도 알림톡 → 가입 후 계좌 등록 시 지급
탈퇴 후 재가입 앱회원 탈퇴 → 같은 전화번호로 재가입 신규 회원으로 생성. 이전 신청이력은 보존 (전화번호 매칭), 포인트는 초기화
전화번호 변경 기존 010-1234 → 010-5678로 변경 마이페이지에서 전화번호 변경 + PASS 재인증 필수. 이전 번호 비회원 데이터는 수동 연결
