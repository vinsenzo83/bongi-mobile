인터넷+TV 상품 티켓

봉이모바일은 광주·전라 지역 8개 직영 매장을 기반으로 한 통신 판매 통합 플랫폼입니다. 고객은 웹/모바일에서 요금 견적 → 상담 신청 → 매장 방문/원격 개통까지 one-stop으로 처리 가능합니다.

🎯 미션

복잡한 통신 3사 요금을 투명하고 단순하게 비교·제공. 오프라인 매장의 전문 상담 + 온라인의 편리함 결합.

🧮 요금 계산기 · 3사 결합할인

3사 결합할인 핵심 차이

통신사결합 상품적용 방식특이사항

KT총액/정액 결합STACK (중복 적용)기본 TV결합 할인 + 추가 할인
KT💎 프리미엄 가족결합별도 계산77K+ 요금제 2회선 이상 · 대표자·구성원 분리
LG U+참쉬운/투게더REPLACE투게더는 85K+ 고가요금제 · 100M 불가
✅ 검증 상태: 1,434개 계산 케이스 전수 테스트 완료 (SKT 360 + KT 834 + LGU+ 240).
