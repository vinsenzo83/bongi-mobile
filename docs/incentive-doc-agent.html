① 기본급

매월 고정 지급, 영업 실적과 무관. 기본급은 2,300,000원 (상담사별로 다를 수 있음 — 본인 급여명세서 확인).

② 등급 체계 — 누적 상담사 포인트 P 기준

등급도달 조건P당 단가페널티 조건
G1P 0 ~ 1520,000원없음

③ 우수 상품 보너스

  • 우수 상품 1건당 10,000원 추가 보너스
  • 우수 = 회사 마진 임계값 이상 (admin이 상품별 지정)
  • 등급업 + 페널티 해제에 모두 활용

⑤ 월 수령액 계산식

월 수령액 =
  기본급
  + 인센티브 = (누적 P) × (등급 단가)
  + 보너스 = (우수 건수) × 10,000
  − 본인 페이백 부담 (페이백 30,000원 초과분)

⑥ 계산 예시 (G2 달성)

조건: 영업 12건 / 누적 20P / 우수 5건 / G2 페널티 없음
기본급2,300,000원
인센티브 (20P × 30,000)+ 600,000
우수 보너스 (5건 × 10,000)+ 50,000
본인 페이백 (50,000원 1건 → 본인 부담 20,000)− 20,000
총 수령액2,930,000원

⑦ 페이백 부담 규칙

구간부담 주체비고
0 ~ 30,000원회사 부담회사가 전액 처리
30,000 ~ 50,000원상담사 부담초과분만큼 본인 인센티브에서 차감
50,000원 초과등록 불가 — admin 승인 필요
💡 예시: 페이백 50,000원 영업 1건 → 회사 30,000원 부담, 본인 20,000원 차감

⑧ 등급업 전략

  • G1 → G2: 16P 도달 + 우수 5건 → 단가 +50% (20k → 30k)
  • G2 → G3: 31P 도달 + 우수 10건 → 단가 추가 +33% (30k → 40k)
  • 페널티 회피: P는 도달했지만 우수 부족 시 손해 큼 — 우수 등록 우선
  • 실시간 시뮬레이터: TM 상담 페이지에서 견적 1건 추가 시 등급 변화 확인
