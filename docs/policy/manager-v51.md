# 팀장 V5.1 인센티브 정책

> 동기화: DB `policy_documents.slug='manager-v51'` ↔ 본 파일

## 구조
팀장(manager role) = 본인 영업 V5(agent와 동일) + **팀 오버라이드** 추가.

## 오버라이드 계산
```
override_raw = (팀원 인센+보너스 합계) × override_rate (기본 0.12)
override_final = override_raw × 페널티 계수
```

## 페널티 매트릭스

| 본인 영업 (completed) | 팀 영업이익률 | 계수 | 결과 |
|---|---|---:|---|
| ≥ 20건 | ≥ 20% | **100%** | 정상 지급 |
| ≥ 20건 | < 20% | 0% | 팀 부진 → 미지급 |
| 10 ~ 19건 | ≥ 20% | 50% | 절반 차감 |
| 10 ~ 19건 | < 20% | 0% | 두 페널티 동시 |
| < 10건 | (무관) | 0% | 본인 영업 부족 |

## 팀 영업이익률 계산
```
team_profit_rate = (팀 매출 − 팀 페이백) / 팀 매출
```

## 정책 조정 가능 항목 (어드민)
- 오버라이드율 (0~1)
- 본인 영업 의무 건수
- 부분 페널티 임계 (50%)
- 팀 영업이익률 임계 (0~1)
- 활성/비활성 토글
