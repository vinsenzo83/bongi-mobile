# 가전렌탈 브랜드별 정책

> 동기화: DB `policy_documents.slug='rental-brand-rules'` ↔ 본 파일 (어드민 편집 시 자동 갱신)

## 공통 환수 규정
- **모든 브랜드**: 1년 이내 반환 또는 3연체 시 수당 환수 (코웨이만 5연체)
- **1년 경과 후**: 환수 없음 → 회사 100% 수수료 확정

## 브랜드별 정책

### LG전자
- 결합: 신규/기존 결합 별도 단가 (모델별 상이)
- 타사보상: 모델별 할인금액 상이
- 반값할인: 수수료 변동 없음
- **특이사항**: 일부 모델 4년 약정 시 월 렌탈료의 400% 지급

### SK매직
- 결합: 기본수수료의 75% 지급
- 타사보상: 반값할인과 중복 불가
- 반값할인: 의무5년→1~6개월차, 의무6,7년→1~12개월차 (타사보상 시 +3개월 추가)
- 환수: 1년 이내 반환 3연체 시

### 코웨이
- 결합: 결합 5% / 동시구매 10%
- 타사보상: 약 10% 추가 (모델별 상이)
- 반값할인: 약정별 (3년→3M / 5년→6M / 6년→9M / 7년→12M)
- 환수: 1년 이내 반환 또는 **5연체** 시
- 중복: 반값+타사보상 불가 / 반값or타사 + 동시구매or결합 가능

### 청호나이스
- 4종 규정 동시 운영: S규정(신규 대부분), P규정(패키지), 재렌탈, 타사보상
- S/P 별도 반값 정책
- 타사보상: J→P규정 수수료 지급

### 교원웰스
- 결합: 수수료 폭 커서 단품 유도 권장
- 환수: 1년 이내 반환 3연체 시

### 루헨스
- 결합: 정수기 100% / 공청기·비데 50%
- 환수: 1년 이내 3연체 시 100% 환수
- 타 프로모션 중복 가능

### 유버스
- 결합: 일부 모델만 가능
- 타사보상: 불가
- 반값: 일부 모델 적용

### 현대큐밍
- 결합: 수수료 50% (정수기끼리 결합 불가)
- 타사보상: 불가
- **신용불량자 전용** (선납 진행 필요)

### 쿠쿠
- 단가 별도 (결합·타사보상)
- 반값: 모델명에 6M/12M 반값 표기
