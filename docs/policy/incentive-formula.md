# 인센티브 계산 공식 (인터넷+TV / 가전렌탈 통일)

> 동기화: DB `policy_documents.slug='incentive-formula'` ↔ 본 파일
> 최종 업데이트: 2026-05-13

## 1. 마진 공식 (공통)

```
margin = rebate × 0.9 − payback − P × 70,000
```

| 항목 | 설명 |
|---|---|
| `rebate × 0.9` | 부가세(VAT) 10% 차감 후 회사 매출 인식 |
| `− payback` | 상담사 페이백 (운영자 입력) |
| `− P × 70,000` | 가중치 P당 회사 부담 (인센티브 + 운영비 평균) |

**인터넷+TV:** 운영자가 통신사 정산표 기준으로 `incentive_products.margin`에 **직접 입력** (자동 계산 코드 없음 — 위 공식은 패턴 분석 결과).

**가전렌탈:** 위 공식으로 **자동 산출** (`rental_recalc_margins_and_premium()` RPC 함수). 수동 override 가능 (`margin_manual_override=true`).

## 2. 가중치 비용 (₩70,000/P)

P 1점당 회사가 부담하는 비용 구성:

| 항목 | 비율 |
|---|---:|
| 상담사 인센티브 평균 (G1~G3 평균 단가) | ~30,000원 |
| 회사 페이백 부담 (추가 페이백 한도 + 정책 비용) | ~20,000원 |
| 운영·관리비 (마케팅·정산·CS) | ~20,000원 |
| **합계** | **70,000원** |

## 3. 가중치 P (point_weight) — 상품별 차등

### 인터넷+TV
| 상품 | P |
|---|---:|
| 인터넷 단독 (100M/500M/1G) | **1.0** |
| 인터넷+TV 결합 | **1.5** |

### 가전렌탈 (rebate 분위수 기반 자동 분류)
| rebate 범위 | P |
|---|---:|
| 580,000원 이상 (상위 25%) | **2.0** |
| 350,000 ~ 580,000원 (중위 50%) | **1.5** |
| 350,000원 미만 (하위 25%) | **1.0** |

> 가전렌탈 P 변경 시 [🔁 마진·Tier·우수상품만 재산출] 버튼으로 일괄 반영.

## 4. Grade 단가

### 인터넷+TV
| Grade | 단가 | 1P당 |
|---|---:|---|
| G1 (기본) | 20,000원/P | — |
| G2 | 30,000원/P | 누적 P ≥ 16, 우수 ≥ 5건 |
| G3 (최고) | 40,000원/P | 누적 P ≥ 31, 우수 ≥ 10건 |

### 가전렌탈
| Grade | 단가 | 1P당 |
|---|---:|---|
| G1 (기본) | 15,000원/P | — |
| G2 | 22,000원/P | 동일 임계값 |
| G3 (최고) | 30,000원/P | 동일 임계값 |

> Grade는 **인터넷+TV + 가전렌탈 통합 누적 P + 우수건수** 기준 자동 결정. 단일 Grade가 양쪽 시스템에 적용되되 단가는 각자.

## 6. 페이백 구조

| 항목 | 의미 | 부담 |
|---|---|---|
| **페이백 정가** | 통신사 정산표 표준 페이백 | 회사 |
| **추가 페이백** | 상담사가 영업 시 추가 약속 (0~50,000원) | 회사 한도까지 + 초과는 상담사 본인 |
| **회사 페이백 한도** | 회사 자동 부담 한도 (인터넷+TV: 30,000원) | 회사 |
| **본인 페이백 차감** | `max(0, 추가 − 한도)` | 상담사 인센티브에서 차감 |

## 7. 가전렌탈 차이점

- 마진 공식: 인터넷+TV와 100% 동일
- 가중치 P: 약정별 차이 X (상품별 고정)
- 차감 항목: P × 70,000만 (가입보너스·기본급분담 X)
- 페이백: 정책 기반 자동 산출 또는 운영자 입력
- **1년 유지 시 100% 수수료 확정** (약정 길이 36/60/72/84 무관)
- 옵션 1,512개 중 S Tier 163건 / A 312건 / B 803건 / C 234건
- 상품 107건 중 S Tier 27건 (우수상품)

## 8. 1건당 인센티브 예시

**G2 상담사, P=1.5 상품 1건:**
- 인터넷+TV: 1.5 × 30,000 = **45,000원**
- 가전렌탈: 1.5 × 22,000 = **33,000원**

**G3 상담사, P=2.0 가전렌탈 고가 모델:**
- 가전렌탈: 2.0 × 30,000 = **60,000원/건**

**G3 상담사, P=1.5 인터넷+TV 결합:**
- 인터넷+TV: 1.5 × 40,000 = **60,000원/건**
