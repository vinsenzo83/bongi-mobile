🗄️데이터 모델 (5 신규 테이블)
테이블역할핵심 컬럼
bongi_mvno_providers MVNO 본사 (5 사업자) code · name · network_carrier · commission_default · contract_status
bongi_mvno_plans 봉이 전용 5 SKU 마스터 plan_code · mvno_provider · monthly_fee · promo_fee · data_gb · commission_amount
bongi_mvno_promos SKU별 프로모션 (1:N) type · title · value · duration_months · condition
bongi_mvno_subscriptions 가입 신청 박제 ticket_number(M-) · signup_type · snapshot · promo_snapshot · agreements · status · source
bongi_mvno_devices 단말기 동시 판매 (옵션) device_code · brand · model · retail_price · subsidy_amount
🔒 RLS: `plans`·`promos`는 anon read · `subscriptions`는 server route만 (`anon insert` + `authenticated all`). `incentive_centers`·`incentive_agents` 재사용 — 봉이 보유 인프라 활용.
