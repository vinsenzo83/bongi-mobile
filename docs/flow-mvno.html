3서비스 워크플로우 (운영 상시)
1
🛒 신청 접수 (storefront)
고객이 `flow-customer-01` 요금제 list → 가입 form 작성 → DB bongi_mvno_subscriptions insert (status=`requested`). 자동 SMS "접수 완료"·Slack #mvno-new alert.
DB: bongi_mvno_subscriptions · API: POST /api/mvno/subscribe
2
🔍 상담사 검토 (어드민)
담당자가 어드민 `flow-admin-03-subscriptions` 큐에서 검토. 본인 확인 유심 결제 선납 모두 OK → `verified` 전환. 누락·오류 시 콜 (자동 전화 X, 수동 발신).
status: requested → verified · 평균 처리: 30분~2시간
3
📤 모빙 본사 전달
검토 완료 신청서를 모빙 본사에 전달. ① API 자동 전달 (모빙 API 키 + endpoint 보유 시) ② 엑셀 일괄 전달 (일 1~2회 batch).
status: verified → sent_to_mobing · 전달 후 본사 처리 시간 평균 4~24h
4
📡 개통 처리 (모빙)
모빙 본사가 통신망(SK·KT·LGU+)에 개통 신청 → 망 사업자가 회선 활성. 봉이는 모빙 webhook 또는 일 1회 batch로 결과 수신.
status: sent_to_mobing → activated · 평균 4~24h
5
✅ 개통 완료 통보
DB status=`activated` 갱신 → 자동 SMS "개통 완료, 사용 가능" + 이용 안내 링크. 영업일 9~21시는 즉시, 야간/주말은 익일 오전.
자동 SMS: 개통 완료 · 자동 이메일: 영수증
6
💰 정산 (월 마감)
월말 모빙 본사로부터 정산 data 수신 → DB `bongi_mvno_settlements` insert → 어드민 `flow-admin-05-kpi` 매장별·SKU별 수수료 집계 → 매장 인센티브 자동 분배.
수수료: SKT 27k·KT 28k·LGU+ 25k (SKU·망별 차등) · 매장별 자동 분배
7
🔄 후속 관리
개통 후 7일·30일 만족도 SMS · 프로모 종료 1개월 전 알림 (7M → 정가 전환) · 미납·해지·MNP 이탈 모니터링 (어드민 KPI에 표시).
자동 SMS: 7D·30D 만족도 / 프로모 종료 30D 전
