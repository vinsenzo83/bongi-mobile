# 봉이 알뜰폰 — 전용 요금제 상품 기획

> 봉이가 MVNO 본사와 제휴해 **봉이 단독 브랜드**로 출시할 요금제 상품 spec
> 출시 단계는 MVNO 본사 1~2곳과 우선 협상 → 확대

---

## 0. 출시 전략

### 0-1. Phase 1 (1차 출시 — 5종)
- 가성비 메인 라인 — LTE 위주 3종 + 5G 1종 + 시니어 안심 1종
- **KT엠모바일 + 미디어로그**와 우선 협상 (시장 점유율 1·2위)

### 0-2. Phase 2 (2차 출시 — 추가 5종)
- 가족 결합·청년 데이터·외국인·소호 사업자 등 세그먼트 확장
- SK텔링크·LG헬로비전 추가

### 0-3. 가격대 전략
- **9,000~14,000원**: 신규·청년·MNP 유인 (첫 3개월 할인)
- **15,000~25,000원**: 메인 가성비 라인
- **25,000~40,000원**: 5G 무제한·프리미엄
