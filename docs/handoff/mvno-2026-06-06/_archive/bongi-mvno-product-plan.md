## 1. 설계 핵심 3가지

### 1-1. 수익은 ②③에 집중 — ①은 마진 0, 순수 유입 입구
- 라이트(①)는 **0원 7개월** 미끼 — CAC 흡수
- 사은품·페이백·마케팅 예산은 ② **봉이 베이직**에 집중
- 점보(③)는 데이터 헤비 업셀 — 라이트·베이직 → 점보 자연 전환

### 1-2. ⑤ 봉이 효도 = 매장 전략 실수요 근거
- 효도폰·세컨폰은 구형·보급형 단말 → **eSIM 미지원 다수**
- → 매장 즉시 수령이 **진짜 수요** (단순 보조 X)
- 8 직영 매장 시너지 + 저해지율 + 가족 결합 자산

### 1-3. 가입 첫 화면 `*#06#` 분기
- **EID 있음** → eSIM 즉시 개통 (전국)
- **EID 없음** → 광주·전남 = 매장 수령 / 그 외 = 택배
- 고객이 스스로 갈라져서 **상담 부하 감소**

## 3. 가입 분기 — `*#06#` 패턴

```
고객 storefront 진입
  → SKU 선택 (① ~ ⑤)
  →
  ┌──────────────────────────────────────────┐
  │ STEP 0 (전체 공통): "단말기 EID 확인하기"   │
  │   사용 중 폰에서 *#06# 입력 → 화면 EID    │
  │   표시 안내                              │
  └──────────────────────────────────────────┘
       │
       ├─ EID 있음 (eSIM 가능 단말) →
       │     ① / ② / ③ / ④ — **eSIM 즉시 개통**
       │     전국 어디서나 5분 내 개통 완료
       │
       ├─ EID 없음 (구형 단말 또는 효도폰) →
       │     ⑤ 효도폰 라인업으로 자동 안내
       │     → 광주·전남: **매장 5분 개통**
       │     → 그 외 지역: 실물 유심 택배 (1~2일)
       │
       └─ "모르겠어요" 클릭 →
              챗봇/상담사 자동 안내 (단말기 모델명 입력)
```

**효과**:
- 자가 분기 = 상담 부하 30~50% 감소
- eSIM 가능자는 즉시 가입 = 전환율 +20%
- 효도폰 라인업은 자연스럽게 ⑤로 유입

## 4. v1 → v2 확정 변수 (다음 단계)

### 4-1. 🔥 가장 중요 — 도매 원가·리베이트 견적
- **봉이 베이직 정가 39,600원 + 9,900원 프로모 7개월**이 8개월차 자연 전환 후에도 마진 흑자 가능한지 검증

- **리베이트 단가**: 가입 1건당 25,000~30,000원 협상 목표

### 4-2. 매장 운영 표준화
- 8 직영 매장 — KT/SKT/LGU+ 망별 **실물 유심 재고 정책**
- **5분 개통 보조 표준 프로세스** 매뉴얼화
- 매장 직원 KPI: 가입 1건당 7,000원·월 15건+ 100,000원 보너스

### 4-3. 사은품·페이백 정책 확정
- 봉이 베이직(②) — 가입 시 5,000P + MNP 5,000P + 유지 5,000P + 추천 10,000P
- 봉이 프리미엄(④) — 25,000원/월 페이백 (24개월 약정)

- 지급 시점 (가입 즉시 vs 30일 후 vs 90일 후)

## 5. 다음 작업 — 사용자 선택 3가지 중 선택

### 옵션 A. 도매처 원가 비교표 작성
- 5 SKU × 4 사업자 (KT엠모바일·미디어로그·SK텔링크·LG헬로비전) 도매 원가 추정 표
- 각 사업자별 협상 우선순위 + 예상 수수료율
- 예상 마진 시뮬레이션 (정가 전환 시·프로모 기간·24개월 LTV)
- **소요 시간**: 30분

### 옵션 B. 매장 운영 가이드
- 8 매장별 망별 유심 재고 정책
- 5분 개통 표준 프로세스 (체크리스트·스크립트)
- 매장 직원 교육 자료
- 효도폰 자녀 동반 가입 시 가족 결합 안내 스크립트
- **소요 시간**: 1시간

### 옵션 C. 챗봇 업셀 스크립트
- 라이트(①) → 베이직(②) 업셀 (7개월 종료 14일 전 알림)
- 베이직(②) → 점보(③) 업셀 (데이터 부족 감지)
- 효도(⑤) 가입자 자녀에게 결합 안내
- 봉이 가전렌탈·인터넷+TV 고객 알뜰폰 크로스셀
- **소요 시간**: 1시간
