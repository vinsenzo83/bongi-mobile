## 1. 모빙 실제 페이지 구조 (캡쳐 분석)

### 상단 progress (4단계)
```
가입접수  →  신청서 작성  →  결제  →  접수완료
```
- 단순 텍스트 + 활성 단계 주황 하이라이트
- 화면 전환은 page 단위 (각 단계 = 1 page)

### 1 page (가입접수) 안 구성
**좌측 — 안내 panel**:
- 휴대폰 mockup 이미지 ("사용중인 번호 그대로" + 모빙 유심)
- "사용 중인 휴대폰에 모빙유심 장착하여 사용" 안내
- **eSIM 출시 박스** (파란색 — 휴대폰 하나로 2개 번호)
- **개통 정보 누락·오입력 시 상담원 전화** 안내 박스 (주황색)

**우측 — 가입정보 form (chip 위주 1 page)**:
1. **가입유형 chip 2개**: `신규가입` / `번호이동`
   - 신규가입 선택 시 노란 tooltip: "제한 대상 유심 SKT간편유심·KT망 바로유심·LG U+망 원칩·타통신사 유심"
2. **통신망 chip 3개**: `SKT망` / `KT망` / `LG U+망`
3. **상품유형 chip 2개**: `후불` / `선불`
4. **요금제 선택** 큰 주황 버튼 → 별도 modal 또는 다음 page

### 하단 sticky CTA
- "계산창 열기 ▼" 토글
- **월 납부금액 0원** 큰 글씨
- **CTA 2개**:
  - 🟧 `가입접수 (유심주문)` (주황) — 실물 유심 택배 패스
  - 🟨 `가입접수 (상담원개통)` (노랑) — 상담사 통화 패스

### 우상단 floating
- 💬 `상담하기` 버튼 (둥근 토스트)

## 2. 봉이 매핑 (v2 단순화)

### 봉이 1 page form 적용
- ❌ 4 step wizard (요금제·유형·정보·약관) **폐기**
- ✅ **1 page 모빙 패턴**: 가입유형 → 통신망 → 상품유형 → 요금제 → 가입자 정보(이름·전화) + 약관 chip 2줄 + sticky CTA 2개

### chip group 매핑

| 모빙 | 봉이 | 봉이 확장 |
|---|---|---|
| 가입유형 (신규·번호이동) | 동일 | 유심만 변경 chip 추가 (3개) |
| 통신망 (SKT·KT·LGU+) | 동일 | 자동 — 봉이 SKU별로 망 미리 정해짐 (라이트·베이직·프리미엄·효도 = LGU+, 점보 = KT) |
| 상품유형 (후불·선불) | 동일 | 봉이는 후불 only (선불 미운영 옵션) |
| 요금제 선택 | 봉이 5 SKU modal 또는 list | 라이트·베이직★·점보·프리미엄·효도 |

### 봉이 CTA 2개 (모빙 그대로)

| 모빙 CTA | 봉이 CTA | 동작 |
|---|---|---|
| 🟧 가입접수 (유심주문) | 🟧 **가입접수 (유심주문)** | eSIM 즉시 또는 실물 유심 택배 |
| 🟨 가입접수 (상담원개통) | 🟨 **가입접수 (상담원개통)** | 콜DB ingest + 상담사 전화 |

## 3. 봉이 단순화 추가 (모빙 대비 줄임)

### 정보 입력 최소화
- 모빙: 이름·생년·주소·이메일 등 N개 (다음 page에서)
- 봉이: **이름·전화** 2개만 (1 page 안에서) → 상세는 가입접수 후 상담원이 전화로 확인

### 약관 단순화
- 모빙: 필수 4종 + 선택 (확장)
- 봉이: **필수 1줄(통합) + 선택 1줄(마케팅)** = 총 2줄
  - 필수: 봉이 알뜰폰 이용약관 + 개인정보 + 망 임대 한 줄로 통합 표시
  - 선택: 마케팅·광고

### 좌측 안내 봉이 색
- 모빙: 노란·파란 박스
- 봉이: 유심 그래픽 봉이 brand 색 (노랑·주황) + eSIM·전화 안내 박스

## 4. EID 분기 (봉이 추가)

모빙에는 없는 봉이 차별 — **`*#06#` EID 자가 분기**:
- 가입 form 진입 전 별도 페이지 (`wf-customer-02-eid-check.html`)
- ✅ EID 있음 → 1 page form + eSIM 옵션 추천
- 📦 EID 없음 (광주·전남) → 매장 5분 개통
- 🚚 EID 없음 (그 외) → 실물 유심 택배

→ 자가 분기로 상담 부하 30~50% 감소.

## 5. 가입 후 flow (간소화)

```
1 page form 제출
  → ticket M00001~ 발급
  → 완료 페이지 (M-ticket + 다음 단계 안내)
  → 24h 내 상담원 통화 (유심주문 시 또는 정보 누락 시)
  → eSIM 즉시 발급 / 실물 유심 1~2일 택배
  → 개통 완료 SMS + 봉이포인트 5,000P 적립
```

## 6. 다른 단계 (신청서 작성·결제·접수완료)

모빙 progress의 나머지 3단계는 봉이 적용 검토:

| 모빙 | 봉이 적용 여부 | 이유 |
|---|---|---|
| 신청서 작성 (2단계) | △ 선택 | 1 page 가입접수에서 이미 받음. 신분증 사진 필요한 경우만 추가 page |
| 결제 (3단계) | ❌ 제거 | 봉이는 후불 only · MVNO 본사가 자체 청구 |
| 접수완료 (4단계) | ✅ `wf-customer-04-complete.html` | M-ticket·다음 단계 |

→ 봉이 실제 단계: **가입접수 (1 page) → 접수완료 (M-ticket)** 2단계.
