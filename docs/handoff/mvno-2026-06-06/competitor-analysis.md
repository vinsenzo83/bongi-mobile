## 2. 모빙 (mobing.co.kr) 상세 패턴 ★ 가장 참고

### 2-1. 요금제 카드 (list 페이지)
- **망 chip** (좌상단 색 배지): 🟦 LGU+ · 🟥 SKT · 🟦 KT
- **요금제명**: "실속 데이터 4.5GB+" · "모빙 300분 15GB" · "[K] 후후 안심 11GB+"
- **데이터 표시** (큰 글씨 + 화살표): `↕️ 4.5GB+1Mbps` · `↕️ 11GB + 매일2GB+3Mbps`
- **통화·문자**: `📞 기본제공+부가 300분` · `✉️ 기본제공` 또는 `📞 300분 / 300건`
- **가격 영역 (우측)**:
  ```
  ~~28,000원~~   월 10원   (빨강 큰 글씨)
  7개월차부터 18,000원   (회색 작은 글씨)
  ```
- **+ 비교 추가** 버튼 (우상단)

### 2-2. 가입 form (receipt 페이지)
- progress 4단계: 가입접수 · 신청서 작성 · 결제 · 접수완료
- 좌측 panel: 휴대폰 mockup + 모빙유심 + eSIM 출시 + 전화 안내
- 우측 form (1 page · chip 4그룹):
  - **가입유형** chip: 신규가입 / 번호이동
    - 신규가입 선택 시 노란 tooltip (제한 유심 안내)
  - **통신망** chip: SKT·KT·LGU+
  - **상품유형** chip: 후불 / 선불
  - **요금제 선택** 큰 주황 버튼
- 하단 sticky:
  - "계산창 열기 ▼" 토글
  - 월 납부금액 큰 글씨
  - **CTA 2개**: 🟧 가입접수(유심주문) · 🟨 가입접수(상담원개통)
- 우상단 💬 상담하기 floating

## 3. 아정당 (ajdmobile.co.kr) 상세 패턴 ★ 단순함의 끝

### 3-1. 요금제 상세보기
- **태그 chip**: LGU+ + **24개월할인** (분홍 chip)
- **요금제명** 큰 글씨: "롱런 무제한 4.5GB + 1Mbps"
- **스펙 설명** (3 row):
  - 📊 4.5GB + 1Mbps → **자세한 한 줄 설명** ("데이터 소진 후 1Mbps로 무제한·SNS 끊김 없이 가능")
  - 📞 기본제공 +부가통화 300분
  - ✉️ 기본제공
- **가격 영역 (우측 하단)**:
  ```
  (VAT포함)
  월 8,900원       (큰 글씨)
  *24개월 이후 14,900원   (작은 글씨)
  ```

### 3-2. 우측 가입 신청 form (1 page · 매우 단순)
- **가입유형** chip: 신규가입 / 번호이동
- **개통방법** chip: **셀프 개통** (1개만 — 자가 개통 강조)
- **유심 보유여부** chip: 보유 / 미보유
- **유심 종류** chip: 일반유심 / NFC유심 (+ "유심 안내" 어두운 chip)
- **고객유형** chip: 개인 (default)
- CTA: 큰 파란 **"온라인 신청하기"** 1개

### 3-3. 차별화 포인트
- **24개월할인** 분홍 chip = 프로모션 명시
- **셀프 개통 단일 chip** = 운영 부하 최소
- **유심 보유 여부** chip = 미보유 시 자동 유심 구매 분기
- 단순 단일 CTA (모빙은 2 CTA)
- 자세한 한 줄 설명 (사용자 친화)

## 4. 모요 (moyoplan.com) 패턴

- **포지션**: 비교·검색 플랫폼 (대리점 X)
- **주력 기능**: 모든 사업자 통합 비교·필터·검색
- **모요개통**: SIM 보유 시 1-step 가입+개통 가능
- **알림**: 카카오톡 진행 알림 + 마이페이지 추적

→ 봉이 직접 참고 점은 적음. 대리점 모델이라 모빙·아정당이 더 적합.

## 5. 봉이 적용 우선순위 (TOP 5)

### 🥇 1순위 — 모빙 패턴 프로모션 표시
- 정상가 strike → 빨강 큰 글씨 프로모 가격
- **"N개월차부터 N원" 작은 회색** 명시
- 봉이 카드 우상단 "**프로모션 7개월**" chip

### 🥈 2순위 — 아정당 단순함
- **개통방법 셀프 개통 단일 chip** (모빙 2 CTA보다 운영 부하 ↓)
- **유심 보유 여부 chip** (미보유 시 자동 유심 구매 안내)
- **24개월할인 / 7개월프로모 / 평생할인** chip — 망 chip 옆에 명시

### 🥉 3순위 — 모빙 좌측 panel
- 휴대폰 mockup + 봉이유심 (브랜드 강조)
- eSIM 출시 박스 (파란색)
- 전화 안내 박스 (주황색)
- "계산창 열기 ▼" 토글 (월 납부금액 큰 글씨)

### 4순위 — 모빙 데이터 표시
- 화살표 아이콘 + 데이터 큰 글씨
- "4.5GB + 1Mbps" / "11GB + 매일2GB + 3Mbps"

### 5순위 — 아정당 자세한 설명
- 데이터 소진 후 속도 안내 (SNS·웹서핑 가능 등 친절한 설명)
- 사용자 친화 한 줄

## 6. 봉이 SKU 카드 최종 양식 (적용 후)

```
┌──────────────────────────────────────┐
│ [LGU+] [🔥 프로모션 7개월] [⭐ 주력]  │
│                                       │
│  봉이 베이직                          │
│  11GB + 매일 2GB + 3Mbps             │
│                                       │
│  📞 기본제공 통화 무제한               │
│  ✉️ 기본제공 문자 무제한               │
│  📊 데이터 소진 후 3Mbps로 무제한      │
│     SNS·웹서핑·동영상 끊김 없음        │
│                                       │
│            ~~39,600원~~  월 9,900원   │
│        7개월차부터 39,600원           │
│                                       │
│   [📦 가입접수 (유심주문)]            │

└──────────────────────────────────────┘
```

→ 모빙(프로모션 빨강 강조 + N개월차부터) + 아정당(자세 설명) + 봉이 단독(주력 ★ chip + 봉이포인트) 결합.

## 7. 가입 form 최종 합의 (5 chip group)

| step | chip group | 옵션 |
|---|---|---|
| 1 | 가입유형 | 신규가입 / 번호이동 / 유심만 변경 (봉이 추가) |
| 2 | 통신망 | SKT·KT·LGU+ (봉이 SKU는 자동 매핑) |
| 3 | 상품유형 | 후불 only (선불 미운영) |
| 4 | 유심 보유여부 | 보유 / 미보유 (← 아정당 적용) |
| 5 | 유심 종류 | 일반유심 / eSIM (봉이는 NFC X) |

+ 이름·전화 2 input + 약관 chip 2 line + sticky CTA 2개 (모빙 패턴)
