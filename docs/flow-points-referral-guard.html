SECTION 4 — 알림 관리 (어드민 17번)
STEP 1 — 알림 채널 정책
카카오 알림톡 (유료) — 2가지만
1. 비회원 가입 유도 (3단계)
1차: 신청 완료 즉시 — "앱 가입 + 계좌 등록하면 사은품 즉시 지급"
2차: 계약 완료 시 — "사은품 OO만원 준비됨 → 앱 가입 → 즉시 입금"
3차: D+7 미가입 — "사은품이 아직 대기 중이에요!"
2. 사은품 지급 완료
"사은품 OO만원 입금 완료" + 계좌 정보
앱 푸시 (무료) — 나머지 전부
1. 신청 상태 변경 — "신청이 접수되었습니다 (KT0311)"
2. 포인트 적립 — "친구초대 가입으로 5,000P 적립!"
3. 포인트 출금 완료 — 출금 승인 시
4. 돈지키미 알림 — D-90 / D-30 / D-7 / D-1
5. 후기 작성 유도 — "계약 완료! 후기 작성하고 15,000P 받으세요"
6. 사은품 지급 완료 — 앱회원 대상
비용 절감 정책: 카카오 알림톡은 건당 유료이므로 비회원 전환(가입 유도)과 사은품 입금 알림 2가지만 사용. 나머지 모든 알림은 앱 푸시(무료)로 처리.

예외 케이스 — 친구초대
상황처리 방법
자기 자신 추천 코드 입력서버에서 자가추천 차단. "본인 코드는 사용할 수 없습니다" 에러.
동일 전화번호 중복 등록이미 추천 등록된 번호 차단. "이미 추천 등록된 번호입니다".
친구가 PASS 인증 안 함추천인 가입 보상 3,000P 보류. 친구가 PASS 인증 완료 시 적립.
추천인이 PASS 인증 안 함계약 보상 보류. 양쪽 모두 PASS 인증 완료 시 적립.
친구가 계약 후 취소계약 보상 미지급 (계약완료 상태만 보상 대상).
추천 코드 존재하지 않음"유효하지 않은 추천 코드입니다" 에러.
