셀프등급 ≠ 실제등급고객이 A등급 신청 → 검수 후 B등급 확정. 보상가격은 보상등급 기준. 고객에게 알림톡 발송.
매입 불가 기기검수 후 매입 불가 판정 → 반송완료 상태 → 고객에게 알림톡 + 반송 안내
위탁업체 API 장애어드민 중고폰 현황에서 API 연동 상태 모니터링. 장애 시 수동 상태 관리.
PASS 인증 실패매입 접수 불가. PASS 인증 완료 필수.
이미 앱회원인데 매입 접수전화번호 매칭 → 기존 회원에 매입 이력 연결. 별도 비회원 생성 안 함.
매입 후 앱 가입전화번호 매칭 → PASS 데이터 자동 연결 → 재인증 불필요 → 앱회원 전환
시세 변동위탁업체 웹훅으로 자동 업데이트. 신청 시점 시세로 매입 진행.
