🎫 9. 티켓 조합 리스트 (전체 105개)
설계 원칙:
· 티켓번호 = 속도 × TV × WiFi 유/무로 결정 (셋톱은 필수 독립, WiFi는 기본 1종 고정)
· WiFi 요금이 0원인 경우(KT 1G / LGU+ 전 속도)는 유/무 구분 없이 1개 티켓
· 셋톱·WiFi 모델 추가·단종 → 기본값 교체 → 티켓번호 영향 없음 (요금만 재계산)
· 티켓번호는 영구 발급 (재사용 X, 비활성만 존재)
