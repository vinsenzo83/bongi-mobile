핵심 — 현금 페이백이란?
현금 페이백 = 전액 현금 지급. 계약 완료 시 bongi_gifts에 "지급 대기" 레코드 자동 생성.
고객이 앱회원 가입 + PASS 본인인증 + 계좌 등록을 모두 완료하면 등록 계좌로 현금 입금.

STEP 3 — 비회원 가입 유도 알림톡 (3단계 자동 발송)
비회원이 신청한 경우 — 현금 페이백 지급을 위해 앱 가입을 유도하는 알림톡 3단계 자동 발송
단계발송 시점내용목적발송
1차 신청 완료 즉시 "앱 가입 + 계좌 등록 시 현금 페이백 즉시 지급" 최초 가입 유도 자동
2차 계약 완료 시 "현금 페이백 OO만원 준비됨 → 앱 가입 → PASS 인증 → 계좌 등록 → 즉시 입금" 구체적 금액 안내 + 절차 안내 자동
3차 D+7 (미가입 시) "현금 페이백이 아직 대기 중이에요 → 계좌 등록 즉시 입금" 리마인더 (긴급감 조성) 자동

예외 케이스
케이스상황처리
비회원 장기 미가입 3차 알림톡(D+7) 이후에도 미가입 비회원 대기 유지. 어드민에서 수동 알림톡 추가 발송 가능.
PASS 인증만 미완료 앱 가입 + 계좌 등록했으나 PASS 미인증 지급 불가. 본인인증 "미인증" 표시. 지급 대기 유지.
계좌 미등록 앱 가입 + PASS 인증했으나 계좌 미등록 지급 불가. 계좌 "미등록" 표시. bongi_user_profiles 계좌 필드 비어있음.
CRM 등록 건 콜센터에서 직접 접수한 건 (티켓번호 없음) 티켓번호 "-" 표시. 상품명은 텍스트로 기록. 현금 페이백 금액 수기 입력.
렌탈 반값할인 현금 지급이 아닌 반값할인 프로모션 현금 페이백 금액에 "반값할인" 표시. 계좌 입금 아닌 월요금 할인 적용.
지급 보류 확인이 필요한 건 (예: 계약 취소 우려, 정보 불일치) 어드민에서 "보류" 클릭 → hold 상태. 확인 후 "지급" 가능.
현금 페이백 금액 변경 어드민에서 현금 페이백 금액 수정 신규 신청부터 적용. 기존 계약 건은 계약 시점 금액 유지.
